# EventEase AI — Smart Celebration Planner
**PromptWars Virtual Hackathon — Indian Celebration Planning Edition**

EventEase AI is an intelligent, user-friendly event planning platform tailored for Indian celebrations including **Birthdays, Weddings & Sangeet, Engagements / Roka, College Fests, Baby Showers / Godh Bharai, Anniversaries, and Corporate Events**.

- **State Preservation:** Saved events, custom expenses, tasks, and guest lists remain 100% intact across all views.

## 🚀 Key Modules & Unified Architecture

1. **🌟 Landing Page:** High-converting welcome experience with hero photograph, 4 category cards with pictures, feature highlights, 3-step process, and quick resume link.
2. **📊 Dashboard Overview:** Hero celebration banner, 5 metric cards, multi-segment progress bar, milestone checklist, and AI planning insights.
3. **👥 Smart RSVP and Guest Management:** Add, edit, remove guests, track status (`Accepted`, `Pending`, `Declined`), shareable digital RSVP link, and dynamic catering cost recalculation.
4. **⚡ AI Budget-Saving Assistant ("Optimize My Budget"):** Identifies category savings, original vs. suggested cost, trade-offs, and per-item accept/revert actions that live-update budget charts.
5. **🎨 Enhanced AI Theme Studio & Mood Board:** 3 distinct themes, best-match recommendations, color swatches with names, aesthetic reference cards, and generative AI visual prompts.
6. **🚨 Event-Day Emergency Assistant:** Contingency playbooks for 7 Indian celebration crises plus natural language emergency query box.
7. **🍽️ AI Food & Catering Planner:** Pure Veg, Non-Veg, and Jain menus with per-plate costs and budget substitutions.
8. **⏱️ Timeline & Interactive Tasks:** Milestone checklist and event-day hour-by-hour Run of Show.
9. **🛍️ Vendor & Procurement Checklist:** Itemized vendor roster with priority, estimated ₹ prices, and booking status.
10. **💌 Multilingual AI Invitations:** English, Hindi (हिंदी), and Marathi (मराठी) with 5 tones and WhatsApp sharing.
11. **🎁 Gifts, Activities & Eco-Friendly Guide:** Indian party games (Tambola, Antakshari), tiered gift ideas, and zero-waste event tips.
12. **💬 Ask EventEase AI:** Context-aware chat assistant synchronized with active celebration parameters (Demo heuristic & Google Gemini API).
13. **📄 Complete Event Plan Dossier Export:** Print-ready master document (`window.print()`).
14. **📝 Intelligent Event Creation Questionnaire:** 4-step wizard with category-specific follow-up questions.

## 🔒 Security & Privacy

- **No Hardcoded Secrets:** API keys and credentials should not be committed to the public repository.
- **API Key Handling:** If users configure a Google Gemini API key, it may be stored in browser `localStorage`. Anyone with access to the browser profile may be able to access it. Requests to the Gemini API transmit the key to Google's service.
- **Privacy:** Avoid entering sensitive personal information into the application. API usage is subject to Google's applicable terms and privacy policies.
- **Future Improvement:** For production deployment, use a secure backend to manage API credentials and protect sensitive information.
